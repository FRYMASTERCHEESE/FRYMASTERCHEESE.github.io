How It Works

How Tap Rush, progress saving, referrals and separate reward records work.

Play

Tap Rush runs for ten seconds and counts manual taps before time expires.

Build progress

Rounds can update points, XP and the personal-best statistic. These values are game progress, not cash.

Save supported progress

An authenticated account can associate supported progress with the player for later sessions.

Referrals

A new account can provide an existing player's referral code. Duplicate and manipulated registrations are not genuine referrals.

Reward records

Pending, verified and paid values are separate from game statistics. The current website records withdrawal requests but does not itself send PayPal or cryptocurrency payments.
