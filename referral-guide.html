Referral System Guide

How referral codes, pending status and genuine referral activity work on FryMasterCheese.

What a referral code does

An account can have a unique referral code. When a new player signs up through a referral link or provides that code during registration, the relationship can be recorded.

Pending versus verified

A pending referral has been recorded but is not the same as a verified referral. Verification allows suspicious or duplicate activity to be kept separate from genuine participation.

What counts as genuine activity?

A genuine referral should represent another person choosing to create their own account. Self-referrals, duplicate accounts and automated registrations should not be used to increase counts.

Referral counts are not cash

A referral status is an account record. It does not automatically promise a payment or create a withdrawable balance.
