Browser & Performance Guide

Troubleshoot slow loading, unusual Tap Rush responsiveness and cloud-save connection problems.

If the site feels slow

Close unnecessary browser tabs, make sure the device is not under heavy load and try a stable connection. A short reaction game can feel different when a device is busy.

If taps feel inconsistent

Check whether the browser is zoomed, whether another overlay is covering the page and whether the touchscreen behaves normally in other apps. Compare several rounds before assuming a single unusual score represents a persistent problem.

If cloud progress does not load

Confirm you are signed into the intended account and have a working internet connection. Local browser progress and authenticated cloud progress are not the same storage mechanism.

If sign-in fails

Check the email address carefully and use the password-reset option if necessary. Email confirmation may also be required depending on the account state.

Before clearing browser data

Clearing site storage can remove locally stored game state. If cloud saving matters to you, confirm you are signed in and that the account loads expected progress before clearing browser data.
