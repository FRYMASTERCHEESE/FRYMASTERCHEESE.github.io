Points, XP, Levels & Best

Understand every major progress statistic on FryMasterCheese and why gameplay values remain separate from money.

Points

Points are cumulative gameplay progress. A completed Tap Rush round adds its successful tap count to the existing total. The daily progress bonus can also add game points once per day.

XP

XP is a second progress measure. Tap Rush can add XP after a completed round and the daily progress bonus can add XP as well.

Levels

The interface calculates a displayed level from XP. A level is a milestone that helps show continued activity; it is not a currency or cash value.

Best

Best stores the strongest single Tap Rush round. Unlike points, it does not add every result together. It only changes when a completed round exceeds the existing record.

Why the separation matters

Game values are created through browser interactions. Browser-side data alone is not strong enough evidence for a real-money obligation because clients can be modified or automated.

Reward-record terminology

Pending describes an amount still in a processing state. Verified is a separately approved balance. Paid is a historical record. These fields are intentionally distinct from points, XP, levels and Best.
