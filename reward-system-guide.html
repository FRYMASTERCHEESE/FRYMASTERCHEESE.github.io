Reward Records Explained

A transparent explanation of pending, verified and paid records and the site's current payout limitations.

Why reward records are separate

Gameplay values and monetary records serve different purposes. Keeping them separate prevents a browser-generated score from being mistaken for a verified financial balance.

Pending

Pending represents an amount in a processing state. It should not be interpreted as proof that a payment has already been sent.

Verified

Verified represents a separately approved record. The withdrawal form checks this balance before a request can be recorded.

Paid

Paid is intended as a historical record for amounts that have completed a legitimate payout process.

What the current website actually does

The current site can record a withdrawal request and update related database balances. It does not itself connect to a PayPal sending API or sign and broadcast cryptocurrency payments.

What would be needed for real payouts?

A production system would need server-side eligibility verification, fraud controls, secure payment credentials, payout execution, error handling, audit records and any applicable legal or tax compliance. Until those systems exist, the site should not claim that a request equals a completed payment.
